# Nature Explorer — iOS

SwiftUI app generated by XcodeGen, with feature code in local Swift packages (`docs/architecture.md` §2–§4,
ADR 0001/0003/0009). Built by Stream C of feature `001-repo-foundations`, Stream B of `002-auth-and-factions`
(sign in with Apple, session, factions, profile) and Stream B of `003-walk-tracking` (walk recording, outbox, history).

## Prerequisites

| Tool | Purpose |
|---|---|
| Xcode 16 (Swift 6 toolchain) | app target, DesignSystem, MapFeature |
| XcodeGen (`brew install xcodegen`) | generates `NatureExplorer.xcodeproj` (git-ignored) |
| git-lfs (`brew install git-lfs`) | model weights in `Resources/Models` |
| Swift 6 toolchain on Linux (optional) | `swift test` for `H3Kit`, `TerritoryRules`, `Core`, `Location`, `Persistence`, `WalkFeature`, `AuthFeature`, `FactionsFeature`, `ProfileFeature`, `DesignSystem` (and `APIClient` when SwiftPM can reach GitHub) without Xcode; `Persistence` needs the system SQLite headers (`libsqlite3-dev`, `/usr/include/sqlite3.h`) because GRDB links `libsqlite3` |
| SwiftLint / SwiftFormat (optional) | `.swiftlint.yml`, `.swiftformat` in this directory |

## Build and test

```bash
cd apps/ios
./scripts/sync-openapi.sh                           # copy the committed OpenAPI snapshot into Packages/APIClient
xcodegen generate                                   # no "missing file" warnings expected
xcodebuild test -scheme NatureExplorer \
  -destination 'platform=iOS Simulator,name=iPhone 16' | tail -5      # ** TEST SUCCEEDED ** (the generator plugin runs during the build)
open NatureExplorer.xcodeproj                       # run: sign in → faction pick → six tabs; Map tab shows Kaunas at zoom 12
```

Linux or macOS without Xcode (everything that does not import SwiftUI — the SwiftUI files sit behind `#if canImport(SwiftUI)`):

```bash
cd apps/ios/Packages/Core && swift test             # AuthSession state machine, validators, presentation (SC-008)
cd ../H3Kit && swift test && cd ../TerritoryRules && swift test
cd ../AuthFeature && swift test && cd ../FactionsFeature && swift test && cd ../ProfileFeature && swift test   # view models
cd ../Location && swift test                        # recorder/estimator fixture parity (SC-002), tracker state machine
cd ../Persistence && swift test                     # GRDB schema, outbox FIFO, back-off, sync coordinator exactly-once (SC-004)
cd ../WalkFeature && swift test                     # walk + history view models over the real in-memory GRDB graph
cd ../APIClient && swift test                       # needs network for SwiftPM; runs swift-openapi-generator
```

Both suites read the shared fixtures from `packages/h3-fixtures/fixtures/` by walking up from the test source file to
the directory containing `pnpm-workspace.yaml`. Set `NATURE_FIXTURES_DIR=/some/dir` to point them elsewhere
(for example at a freshly generated copy). A missing or malformed fixture fails the test naming the file and the
JSON path of the first invalid field.

## Xcode Cloud

Connect the repository in App Store Connect (owner action, `plan.md` "Owner actions"), then create workflows on the
`NatureExplorer` scheme with the project path `apps/ios/NatureExplorer.xcodeproj`:

| Workflow | Trigger | Actions |
|---|---|---|
| PR | pull request | build + **unit tests** (`NatureExplorerTests`) — target < 20 min (SC-003) |
| Merge | push to the integration branch | tests + TestFlight internal |
| Tag | tag | TestFlight external / App Store |
| Nightly (placeholder) | schedule | XCUITests once feature 003 adds user flows; kept off the PR workflow to stay within the 25 h/month budget |

`ci_scripts/ci_post_clone.sh` runs before every build: it installs XcodeGen and git-lfs, pulls the LFS weights and
generates the project. It fails the build if `git lfs pull` fails.

## Configuration

- **Bundle id**: `com.natureexplorer.app` in `project.yml` is final (owner confirmed 2026-09-07). Set
  `DEVELOPMENT_TEAM` once the App ID exists, before the first TestFlight upload.
- **Sign in with Apple**: `NatureExplorer/NatureExplorer.entitlements` carries `com.apple.developer.applesignin`
  (`CODE_SIGN_ENTITLEMENTS` in `project.yml`). The owner must also enable the capability on the App ID in the developer
  portal and set the API's `APPLE_CLIENT_IDS` to the bundle id; in the simulator the button works when the simulator
  is signed into an Apple ID, otherwise use the API's `dev:apple-stub` (`specs/002-auth-and-factions/quickstart.md` §A.2).
- **API**: the Info.plist key `API_BASE_URL` (default `http://localhost:3000`, read by `AppConfig.apiBaseURL`) points
  the generated client at the API; `NSAllowsLocalNetworking` permits the plain-HTTP development server. Tokens live in
  the Keychain (`KeychainStore`, one generic-password item, after-first-unlock, this device only); the last profile is
  cached in `UserDefaults` so an offline launch still reaches the tabs.
- **OpenAPI client**: `Packages/APIClient` is generated at build time by `swift-openapi-generator` from
  `Sources/APIClient/openapi.json`, a copy of `packages/api-schema/openapi.json`. After a route change:
  `pnpm --filter @nature/api-schema snapshot && apps/ios/scripts/sync-openapi.sh`. Never edit the JSON by hand and never
  commit generated Swift. Until the snapshot package exists, `scripts/sync-openapi.sh --from-contract` converts
  `specs/002-auth-and-factions/contracts/openapi.yaml` (marked `x-source` = TEMPORARY in the document).
- **Walks (feature 003)**: `Info.plist` declares `UIBackgroundModes = [location]` (audio arrives with 006),
  `NSLocationWhenInUseUsageDescription` and `NSMotionUsageDescription` (English placeholders marked `TODO(owner)`) and
  `BGTaskSchedulerPermittedIdentifiers = [com.natureexplorer.app.sync]`. Location is read only during a walk started
  from the foreground, under When-In-Use with a `CLBackgroundActivitySession` — the app never asks for Always
  (Constitution VII). Every server call of a walk (create, sample batches of ≤ 200 every 60 s, finish) goes through the
  GRDB outbox and `SyncCoordinator`, which drains it with exponential back-off on foreground, connectivity
  (`NWPathMonitor`), background refresh and a 60 s timer while recording; walks finished offline show a provisional
  summary until the server's `WalkSummary` replaces it. The local database is `Application Support/nature.sqlite`
  (`WalkDatabase.openDefault()`, in-memory fallback with a warning). Raw samples of uploaded walks are deleted after
  7 days at launch (`AppContainer.resumeWalks()`), which also finishes a walk left recording by a kill.
- **`LivePath` for feature 005**: `AppContainer.walks.livePath` is the `@Observable @MainActor` model written only by
  `WalkTracker` — `points` (accepted, raw), `hexEstimates` (metres per res-9 cell, sorted), `currentCell`,
  `currentCellMeters`, `distanceM`, `movingSeconds`, `hexCount`, `isPaused`, `isRecording`, `waitingForGPS`. The map
  layer observes it and redraws; nothing in it is authoritative (`Packages/Location/README.md`).
- **Basemap**: OpenFreeMap `liberty` (global, no key). Override the style with the Info.plist key `MAP_STYLE_URL`
  (read by `MapConfig.fromBundle`), e.g. for a self-hosted PMTiles style. The attribution
  "© OpenStreetMap contributors, © OpenFreeMap" stays visible on the map.
- **MapLibre**: SPM `https://github.com/maplibre/maplibre-gl-native-distribution` 6.x, depended on only by
  `MapFeature`; the resolved version is frozen in `Package.resolved` once generated on macOS.
- **H3 core**: `scripts/vendor-h3.sh v4.2.1` re-vendors the C sources (Apache 2.0, `Packages/H3Kit/Sources/CH3/LICENSE`).
