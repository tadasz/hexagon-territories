# Tasks: Repo Foundations

**Input**: Design documents from `/specs/001-repo-foundations/` (`plan.md`, `research.md`, `data-model.md`, `contracts/openapi.yaml`, `quickstart.md`)

**Prerequisites**: `plan.md` (required), `spec.md` (user stories), `data-model.md`, `contracts/`, `research.md`

**Tests**: Requested by the spec (Constitution V and FR-002/FR-004/FR-005 all demand fixture-driven and integration tests), so test tasks are included and are part of each stream.

**Organization**: Tasks are grouped into **five work streams**. Streams A–D run **in parallel** on disjoint directories (each stream owns only the paths listed in its header and must not touch anything else); Stream E runs after A–D and owns the root-level wiring. Each task maps to one pull request and carries a one-line acceptance check (`→ Check:`).

## Format: `[ID] [P?] [Stream] [Story] Description — paths → Check: acceptance`

- **[P]**: can run in parallel with other [P] tasks in the same stream (different files, no dependency on an unfinished task)
- **[A]…[E]**: owning stream; **[US1]…[US4]**: user story from `spec.md` for traceability
- Root files already created by the planner and **owned by nobody in A–D**: `package.json`, `pnpm-workspace.yaml`, `turbo.json`, `tsconfig.base.json`, `.tool-versions`, `.editorconfig`, `.prettierrc`, `.prettierignore`, `eslint.config.mjs`. Only Stream E may edit them.
- Package names: `@nature/territory-rules`, `@nature/h3-fixtures`, `@nature/api` (see `plan.md` "Package and Target Names"). Every TS workspace defines the scripts `build`, `test`, `lint`, `typecheck`, `clean` and extends `../../tsconfig.base.json`.
- `pnpm-lock.yaml` is scratch for A and B (do not hand it over); Stream E commits it.

## Stream ownership

| Stream | Owns only | Story |
|---|---|---|
| **A — rules** | `packages/territory-rules/`, `packages/h3-fixtures/` | US1 |
| **B — api** | `apps/api/`, `infra/`, `.github/workflows/api.yml`, `Makefile` | US2 |
| **C — ios** | `apps/ios/` | US3 (+ Swift half of US1) |
| **D — ml** | `ml/`, `.gitattributes`, `docs/licences.md` | US4 |
| **E — integration** | root files, `.gitignore`, `README.md`, `CLAUDE.md`, `pnpm-lock.yaml`, `apps/ios/Resources/Models/*.onnx` (LFS commit), `specs/001-repo-foundations/` | all |
