# Tasks: Walk Tracking

**Input**: Design documents from `/specs/003-walk-tracking/` (`plan.md`, `research.md`, `data-model.md`, `contracts/openapi.yaml`, `quickstart.md`)

**Prerequisites**: `plan.md` (required), `spec.md` (user stories), `data-model.md`, `contracts/`, `research.md`

**Tests**: Requested by the spec (Constitution V; FR-019, FR-020, SC-001, SC-002, SC-004, SC-005, SC-007, SC-008 name tests explicitly), so test tasks are part of every stream and are listed inside the task that produces the code they cover.

**Organization**: Tasks are grouped into **three work streams**. Streams A and B run **in parallel** on disjoint directories (each stream edits only the paths in the "Stream ownership" table); Stream C runs after A and B are merged and owns root files and docs. Each task maps to one pull request and carries a one-line acceptance check (`→ Check:`). Semantics both streams must share are in `plan.md` "Shared Semantics" — implement them from there, not from each other's code. Feature 002 is being implemented at the same time: the "Dependencies on 002" table in `plan.md` says what each stream waits for or codes against.

## Format: `[ID] [P?] [Stream] [Story] Description — paths → Check: acceptance`

- **[P]**: can run in parallel with other [P] tasks in the same stream (different files, no dependency on an unfinished task)
- **[A]**/**[B]**/**[C]**: owning stream; **[US1]…[US5]**: user story from `spec.md` for traceability (Stream C tasks carry the stories they close)
- Root files (`package.json`, `pnpm-workspace.yaml`, `turbo.json`, `tsconfig.base.json`, `eslint.config.mjs`, `.prettierrc`, `.prettierignore`, `.gitignore`, `README.md`, `CLAUDE.md`, `pnpm-lock.yaml`, `.github/workflows/*`, `docs/**`) are **owned by nobody in A–B**; only Stream C edits them. A and B may install dependencies package-locally but never hand over `node_modules`, `dist`, `.build` or a lockfile.
- Never edit `packages/territory-rules/**`, `packages/h3-fixtures/**`, `apps/ios/Packages/TerritoryRules/**` or `docs/territory-rules.md` in this feature: no rule changes (Constitution II).
