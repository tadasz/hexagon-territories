# Tasks: Auth and Factions

**Input**: Design documents from `/specs/002-auth-and-factions/` (`plan.md`, `research.md`, `data-model.md`, `contracts/openapi.yaml`, `quickstart.md`)

**Prerequisites**: `plan.md` (required), `spec.md` (user stories), `data-model.md`, `contracts/`, `research.md`

**Tests**: Requested by the spec (Constitution V; FR-010, FR-014, FR-016, SC-004–SC-008 name tests explicitly), so test tasks are part of every stream and are listed inside the task that produces the code they cover.

**Organization**: Tasks are grouped into **three work streams**. Streams A and B run **in parallel** on disjoint directories (each stream edits only the paths in the "Stream ownership" table); Stream C runs after A and B are merged and owns root files and docs. Each task maps to one pull request and carries a one-line acceptance check (`→ Check:`). Semantics both streams must share are in `plan.md` "Shared Semantics" — implement them from there, not from each other's code.

## Format: `[ID] [P?] [Stream] [Story] Description — paths → Check: acceptance`

- **[P]**: can run in parallel with other [P] tasks in the same stream (different files, no dependency on an unfinished task)
- **[A]**/**[B]**/**[C]**: owning stream; **[US1]…[US6]**: user story from `spec.md` for traceability (Stream C tasks carry the stories they close)
- Root files (`package.json`, `pnpm-workspace.yaml`, `turbo.json`, `tsconfig.base.json`, `eslint.config.mjs`, `.prettierrc`, `.prettierignore`, `.gitignore`, `README.md`, `CLAUDE.md`, `pnpm-lock.yaml`, `.github/workflows/*`, `docs/**`) are **owned by nobody in A–B**; only Stream C edits them. A and B may install dependencies package-locally but never hand over `node_modules`, `dist`, `.build` or a lockfile.
- Package names: `@nature/api` (exists), `@nature/api-schema` (new); Swift packages `Core`, `APIClient`, `AuthFeature`, `FactionsFeature`, `ProfileFeature` (new). Every TS workspace defines `build`, `test`, `lint`, `typecheck`, `clean`.
- Environment (`plan.md` "Environment notes"): Stream A has a local Postgres (`DATABASE_URL=postgres://nature:nature@localhost:5432/nature`) but no Docker/MinIO; Stream B has the Swift 6.2.1 Linux toolchain but no Xcode; nobody has git-lfs.
